# 레벨별 읽기 글 만들기

인자: 목표 레벨(필수, `a1` `a2` `b1` `b2` `c1`)과 편수(선택, 기본 1). 예: `/reading-gen a2 2`.
레벨이 없거나 틀리면 쓰지 않고 사용법을 알린다.

이 스킬은 글을 **쓰고 고치기만** 한다. 레벨에 맞는지는 측정 명령이 판단하고, 저장도 저장 명령이 한다.
글은 이 Claude Code 세션에서 직접 쓴다. Anthropic API나 다른 Claude 실행(CLI 등)을 부르지 않는다.

명령은 모두 `web` 폴더에서 실행한다.

- 측정: `npm run --silent reading:measure -- <초안> --json` (통과 0, 미달 1, 입력 오류 2)
- 저장: `npm run --silent reading:save -- <초안>` (다시 재서 통과할 때만 저장)
- 허용 단어: `npm run --silent reading:words -- <레벨>` (그 레벨 이하 단어를 레벨별로)

## 꼭 지킬 것

- 측정을 건너뛰지 않는다. 통과했는지는 측정 결과의 `pass`로만 본다. "거의 통과"는 미달이다.
- 저장 위치(`web/data/readings/`)에 직접 파일을 쓰거나 옮기지 않는다. 저장은 저장 명령으로만 한다.
- 예외 목록(`web/scripts/reading/exceptions.txt`)을 고치지 않는다. 더할 만한 단어가 보이면 끝날 때 사용자에게 제안만 한다.
- 기준(넘는 단어 5%, 길이)을 바꾸거나 우회하지 않는다.

## 편마다 하는 일

편수만큼 아래 1~6을 되풀이한다. 한 편이 실패해도 다음 편으로 간다.

### 1. 주제 고르기

- 이미 만든 글의 제목과 주제를 본다: `grep -rh "^title:\|^topic:" web/data/readings 2>/dev/null`. 이번 실행에서 앞서 만든 편도 포함해 겹치지 않는 주제를 고른다.
- **A1~A2**: 일상, 사람, 장소 이야기(가족의 주말, 시장, 새 이웃, 버스 여행 등). 시사 글이 아니다(`news: false`).
- **B1 이상**: 최신 트렌드와 이슈를 주로 고른다. 시사 글이면(`news: true`):
  - 웹 검색으로 최근 주제를 찾고, 쓸 사실은 **서로 다른 도메인 두 곳 이상**에서 확인한다. 검색 결과의 요약은 확인이 아니다. 페이지를 열어 읽는다. 한 곳에만 있는 사실, 숫자, 인용은 쓰지 않는다.
  - 쓰기 전에 두 곳에서 확인한 사실만 짧은 목록으로 적어 둔다. 본문의 구체적인 사실(날짜, 숫자, 순위, 사건, 사람의 말, 과거의 흐름)은 이 목록에 있는 것만 쓴다. 목록 밖에서는 상식 수준의 설명(얼음이 햇빛을 반사한다 등)과 의견임이 분명한 문장만 쓴다.
  - 확인한 페이지 주소를 `sources`에 적는다(서로 다른 도메인 2개 이상). 본문에는 출처를 쓰지 않는다.
  - 기사 문장을 옮기거나 기사 하나를 바꿔 쓰지 않는다. 사실만 가져와 새로 쓴다.
  - 날짜가 중요한 사실은 확인한 시점을 기준으로 쓰고, 단정하기 어려운 전망은 쓰지 않는다.
- B1 이상이라도 시사가 아닌 주제를 고를 수 있다. 그때는 `news: false`이고 출처가 없어도 된다.

### 2. 쓰기 전에

- A1·A2는 쓰기 전에 허용 단어 명령으로 그 레벨 이하 단어를 본다. 목록에 없는 단어는 쓰지 않는다고 생각하고 쓴다.
- B1 이상은 단어가 많으므로 필요할 때(고칠 때 바꿀 단어를 찾을 때 등) 본다.

### 3. 쓰기

초안을 `web/data/reading-drafts/<레벨>-<짧은 이름>.md`에 쓴다(git에서 무시되는 폴더다). 형식:

```
---
title: A Market Morning
topic: a family shopping at a Saturday market
level: a1
news: false
revisions: 0
sources:
---
본문 문단들…
```

- 시사 글은 `news: true`로 하고 `sources:` 아래에 `  - https://…` 줄로 주소를 적는다.
- 본문은 제목 없이 문단만 쓴다(마크다운 제목, 목록, 굵게 쓰지 않는다). 제목은 `title`에만 둔다.
- 길이(본문 전체 단어 수): A1 약 150(120~180), A2 약 250(200~300), B1 약 350(280~420), B2 약 500(400~600), C1 약 650(520~780).
- 어휘와 뜻:
  - 쉬운 단어도 어려운 뜻으로 쓰지 않는다(예: A1 글에서 run을 "운영하다", fair를 "공정한"으로). 측정은 단어 단위라 이것을 잡지 못한다.
  - 목표 레벨보다 어려운 구동사와 관용구를 쓰지 않는다(예: A1 글에서 put up with, carry out).
- 문법과 문장 길이(측정의 평균 문장 길이는 참고값이다):
  - **A1**: 현재 단순·현재 진행·과거 단순, can, 간단한 will·going to. 대부분 10단어 이하의 짧은 문장. 관계절, 수동태, 가정법을 쓰지 않는다. and·but·because 정도로만 잇는다.
  - **A2**: A1에 더해 과거 진행, 비교급·최상급, when·because·so 절, 간단한 1형 조건문. 대부분 14단어 이하.
  - **B1**: 현재완료, 간단한 수동태, who·which·that 관계절, 1·2형 조건문, 간단한 간접 화법. 평균 18단어 안팎.
  - **B2**: 완료 시제와 수동태를 자유롭게, 간접 화법, 다양한 연결어(however, although, as a result). 평균 22단어 안팎.
  - **C1**: 문법 제한 없음. 다만 문학적이거나 드문 표현보다 분명한 글을 쓴다.
- 철자는 영국식이되 -ize를 쓴다(colour, centre, favourite, realize, recognize, organize). 단 analyse, practise(동사)는 -se다.
- 일반 단어를 대문자로 써서 고유명사로 빠지게 하지 않는다. 사람·장소 이름은 필요한 만큼만 쓴다.
- 숫자는 꼭 필요할 때만 쓴다.

### 4. 재기

측정 명령을 `--json`으로 실행한다. `pass`가 true면 5로 간다.

### 5. 고치기 (최대 3번)

미달이면 측정 결과를 보고 걸린 부분만 고친다. 고칠 때마다 `revisions`를 1 늘리고 다시 잰다(4). 고치기는 최대 3번이다.

- `above`의 단어마다: 본문에 나온 모양(`forms`)을 찾아 허용 단어로 바꾸거나 문장을 바꿔 쓴다. 뜻이 바뀌거나 사실이 틀어지지 않게 한다.
- 레벨이 `null`("목록에 없음")인 단어는 먼저 철자 차이(미국식 철자, -ise)인지 본다. 철자만 고치면 되는 경우가 많다.
- 길이가 범위 밖이면(`reasons`) 문장을 더하거나 줄인다. 더할 때도 허용 단어로 쓴다.
- 시사 글에서 단어를 바꿀 때 확인한 사실과 어긋나지 않게 한다.
- 3번 고쳐도 미달이면 이 편은 저장하지 않고 실패로 둔다(초안은 그대로 둔다). 마지막 측정의 미달 이유를 기억해 둔다.

### 6. 저장

시사 글은 저장하기 전에 본문을 사실 목록과 한 문장씩 다시 대조한다. 목록에 없는 구체적인 사실이 있으면 빼거나 목록의 사실로 바꾸고 다시 잰다(고치기 횟수에 넣지 않는다).

통과하면 저장 명령을 실행한다. 저장 명령이 출력한 파일 경로를 기억해 둔다.
저장 명령이 미달이나 입력 오류(출처 부족, 같은 이름 등)로 거부하면, 이유를 고칠 수 있으면 고쳐 다시 저장한다(입력 오류는 고치기 횟수에 넣지 않는다). 고칠 수 없으면 실패로 둔다.

## 끝나면

편마다 한 줄씩 결과를 보여 준다.

- 저장한 편: 파일 경로, 제목, 비율(%), 고친 횟수
- 실패한 편: 제목(또는 주제), 실패 이유(마지막 미달 이유)

이어서, 측정에서 "목록에 없음"으로 걸렸지만 실제로는 목표 레벨 수준의 기본 단어로 보이는 것이 있으면 예외 목록 후보로 제안한다(파일은 고치지 않는다). 형식: `단어 레벨` 한 줄씩.
