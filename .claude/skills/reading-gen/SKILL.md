# 레벨 단어를 덮는 이야기 만들기

인자: 목표 레벨(필수, `a1` `a2` `b1` `b2` `c1`)과 권수(선택, 기본 1). 예: `/reading-gen a2`, `/reading-gen b1 2`.
레벨이 없거나 틀리면 쓰지 않고 사용법을 알린다.

목표는 두 가지다. 레벨의 단어 전체를 이야기들이 조금씩 덮어 가는 것, 그리고 읽고 싶은 서사가 있는 것.
이 스킬은 이야기를 **쓰고 고치기만** 한다. 레벨에 맞는지는 측정 명령이 판단하고, 저장도 저장 명령이 한다.
이야기는 이 Claude Code 세션에서 직접 쓴다. Anthropic API나 다른 Claude 실행(CLI 등)을 부르지 않는다.

명령은 모두 `web` 폴더에서 실행한다.

- 단어 뽑기: `npm run --silent reading:pick -- <레벨> --json` (아직 덮이지 않은 그 레벨 단어를 무작위로)
- 측정: `npm run --silent reading:measure -- <초안> --json` (장마다 결과. 통과 0, 미달 1, 입력 오류 2)
- 저장: `npm run --silent reading:save -- <초안>` (다시 재서 통과할 때만 저장)
- 덮기 현황: `npm run --silent reading:coverage` (레벨마다 덮인 수와 남은 수)
- 허용 단어: `npm run --silent reading:words -- <레벨>` (그 레벨 이하 단어를 레벨별로)

## 꼭 지킬 것

- 측정을 건너뛰지 않는다. 통과했는지는 측정 결과의 `pass`로만 본다. "거의 통과"는 미달이다.
- 저장 위치(`web/data/readings/`)에 직접 파일을 쓰거나 옮기거나 지우지 않는다. 저장은 저장 명령으로만 한다.
- 예외 목록(`web/scripts/reading/exceptions.txt`)을 고치지 않는다. 더할 만한 단어가 보이면 끝날 때 사용자에게 제안만 한다.
- 기준(장마다 넘는 단어 5%, 장 길이, 장 수 6~8)을 바꾸거나 우회하지 않는다.
- **넘긴 단어를 억지로 쓰지 않는다.** 단어를 넣으려고 어색한 문장, 뜬금없는 장면, 말이 안 되는 전개를 만들지 않는다. 자연스럽게 들어가는 것만 쓰고, 다 쓰지 못해도 된다(최소 개수는 없다). 이야기가 자연스러운 것이 단어 수보다 먼저다.

## 권마다 하는 일

권수만큼 아래 1~6을 되풀이한다. 한 권이 실패해도 다음 권으로 간다.

### 1. 단어 받기

- 덮기 현황을 한 번 실행해 그 레벨의 덮인 수를 기억해 둔다(끝 요약에 쓴다).
- 단어 뽑기로 넘긴 단어 목록을 받는다. 남은 단어가 없으면 그 레벨은 다 덮였다고 알리고 멈춘다.
- A1·A2는 허용 단어 명령으로 그 레벨 이하 단어도 본다. 목록에 없는 단어는 쓰지 않는다고 생각하고 쓴다.

### 2. 주제와 줄거리

- 이미 만든 글과 이야기의 제목·주제·줄거리를 본다: `grep -rh "^title:\|^topic:\|^summary:" web/data/readings 2>/dev/null`. 이번 실행에서 앞서 만든 권도 포함해 겹치지 않게 고른다. 주제만이 아니라 배경(장소, 가족 구성, 큰 사건)과 등장인물 이름도 되도록 겹치지 않게 한다.
- 넘긴 단어를 훑어보고, 그중 **많은 단어가 자연스럽게 들어갈** 배경과 사건을 고른다. 단어 몇 개가 함께 어울리는 무리(장소, 일, 계절, 물건 등)를 찾으면 고르기 쉽다.
- 레벨에 맞는 이야기를 고른다.
  - A1·A2: 사람, 집, 학교, 일, 여행, 동물처럼 일상에 가까운 이야기. 갈등과 결말은 단순하되 분명하게.
  - B1 이상: 인물의 고민, 관계, 선택, 작은 수수께끼 등 서사를 더 풍부하게. 요즘 이슈(기후, 기술, 일하는 방식 등)를 배경으로 쓸 수 있다. 소설이므로 실제 사건의 구체적 사실(날짜, 숫자, 실제 인물의 이름이나 말)을 지어내지 않는다. 등장인물과 장소는 지어낸 것으로 쓴다.
- 줄거리 설계를 `web/data/reading-drafts/<레벨>-<짧은 이름>.plan.md`에 먼저 적는다: 등장인물(이름, 성격, 관계), 배경, 갈등, 전환점, 결말, 장별 요약(6~8장, 장마다 한두 줄과 그 장에 넣을 넘긴 단어 몇 개). 쓰는 동안 이 설계를 기준으로 한다.

### 3. 장마다 쓰기

초안을 `web/data/reading-drafts/<레벨>-<짧은 이름>.md`에 쓴다(git에서 무시되는 폴더다). 형식:

```
---
title: The Lost Key
kind: story
level: a1
summary: Mia finds an old key in her grandmother's garden and learns a family secret.
revisions:
  - 0
  - 0
given:
  - garden
  - key
---
## A Box in the Garden

본문 문단들…

## The Old Door

본문 문단들…
```

- `revisions`는 장마다 한 줄(그 장을 고친 횟수), `given`은 단어 뽑기가 준 목록 전체다(JSON 목록을 한 줄에 한 단어씩 그대로 옮긴다).
- 장은 `## 장 제목` 줄로 나눈다. 장 제목과 책 제목도 측정한다(넘는 단어를 쓰지 않는다). 제목에 번호("Chapter 1")는 붙이지 않는다.
- 장 수 6~8개. 장 길이(장 제목 포함 단어 수): A1 약 150(120~180), A2 약 250(200~300), B1 약 350(280~420), B2 약 500(400~600), C1 약 650(520~780).
- 한 장씩 쓴다. 쓰기 전에 줄거리 설계와 앞 장을 다시 보고, 등장인물 이름·성격·사건이 어긋나지 않게 이어 쓴다. 장마다 작은 사건이나 질문을 남겨 다음 장으로 이어지게 한다.
- 등장인물 이름은 처음 나오는 장에서 문장 중간에도 한 번 쓴다(측정이 이름을 고유명사로 알아보게).
- 본문에는 마크다운 목록, 굵게, 다른 제목을 쓰지 않는다.
- 어휘와 뜻:
  - 쉬운 단어도 어려운 뜻으로 쓰지 않는다(예: A1에서 run을 "운영하다", fair를 "공정한"으로). 측정은 단어 단위라 이것을 잡지 못한다.
  - 목표 레벨보다 어려운 구동사와 관용구를 쓰지 않는다(예: A1에서 put up with, carry out).
- 문법과 문장 길이(측정의 평균 문장 길이는 참고값이다):
  - **A1**: 현재 단순·현재 진행·과거 단순, can, 간단한 will·going to. 대부분 10단어 이하의 짧은 문장. 관계절, 수동태, 가정법을 쓰지 않는다. and·but·because 정도로만 잇는다.
  - **A2**: A1에 더해 과거 진행, 비교급·최상급, when·because·so 절, 간단한 1형 조건문. 대부분 14단어 이하.
  - **B1**: 현재완료, 간단한 수동태, who·which·that 관계절, 1·2형 조건문, 간단한 간접 화법. 평균 18단어 안팎.
  - **B2**: 완료 시제와 수동태를 자유롭게, 간접 화법, 다양한 연결어(however, although, as a result). 평균 22단어 안팎.
  - **C1**: 문법 제한 없음. 다만 문학적이거나 드문 표현보다 분명한 글을 쓴다.
- 대화문을 써도 된다. 대화도 같은 어휘·문법 기준을 따른다.
- 철자는 영국식이되 -ize를 쓴다(colour, centre, favourite, realize, recognize, organize). 단 analyse, practise(동사)는 -se다.
- 일반 단어를 대문자로 써서 고유명사로 빠지게 하지 않는다.
- 숫자는 꼭 필요할 때만 쓴다.

### 4. 재기

모든 장을 쓴 뒤(또는 장을 쓸 때마다) 측정 명령을 `--json`으로 실행한다. 결과의 `chapters`가 장마다의 측정이고 `reasons`에 미달 장 번호가 나온다. `pass`가 true면 6으로 간다.

### 5. 고치기 (장마다 최대 3번)

미달인 장만, 걸린 부분만 고친다. 그 장을 고칠 때마다 그 장의 `revisions`를 1 늘리고 다시 잰다(4).

- 그 장의 `above`의 단어마다: 본문에 나온 모양(`forms`)을 찾아 허용 단어로 바꾸거나 문장을 바꿔 쓴다. 이야기가 어긋나지 않게 한다.
- 레벨이 `null`("목록에 없음")인 단어는 먼저 철자 차이(미국식 철자, -ise)인지 본다.
- 문장 첫머리에서 넘는 단어로 잡힌 이름은, 그 이름을 다른 곳에서 문장 중간에 쓰면 고유명사로 빠진다.
- 길이가 범위 밖이면 그 장에 문장을 더하거나 줄인다. 더할 때도 허용 단어로 쓴다.
- 장 수가 범위 밖이면 장을 나누거나 합친다(고치기 횟수에 넣지 않는다).
- 어떤 장을 3번 고쳐도 미달이면 이 권은 저장하지 않고 실패로 둔다(초안은 그대로 둔다). 마지막 측정의 미달 이유를 기억해 둔다.

### 6. 저장

통과하면 저장 명령을 실행한다. 저장 명령이 출력한 파일 경로와 새로 덮은 단어 수를 기억해 둔다.
저장 명령이 미달이나 입력 오류(같은 이름 등)로 거부하면, 이유를 고칠 수 있으면 고쳐 다시 저장한다(입력 오류는 고치기 횟수에 넣지 않는다). 고칠 수 없으면 실패로 둔다.
저장한 뒤 덮기 현황을 다시 실행한다.

## 끝나면

권마다 결과를 짧게 보여 준다.

- 저장한 권: 파일 경로, 제목, 장 수, 장마다 비율(%), 넘긴 단어 수와 그중 쓴 수, 새로 덮은 단어 수, 그 레벨의 덮인 비율(저장 전 → 저장 뒤)
- 실패한 권: 제목(또는 주제), 실패 이유(마지막 미달 이유)

이어서, 측정에서 "목록에 없음"으로 걸렸지만 실제로는 목표 레벨 수준의 기본 단어로 보이는 것이 있으면 예외 목록 후보로 제안한다(파일은 고치지 않는다). 형식: `단어 레벨` 한 줄씩.
